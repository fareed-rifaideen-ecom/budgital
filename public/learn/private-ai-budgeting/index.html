AI and privacy guide

Private AI budgeting: a safer pattern

Core principle: keep the source-of-truth budget local and make AI an optional interpretation layer. Send the smallest useful aggregate snapshot, explain it, and keep a deterministic fallback.

What to send

A helpful monthly read can use the selected month, total income, total expenses, total budget, amount left, category totals, and existing local rule-based insights. It usually does not need merchant descriptions, transaction IDs, dates, account numbers, or raw CSV rows.

What to show before sending

  • Which fields will leave the browser.
  • That the model may be wrong or incomplete.
  • That the result is informational, not financial advice.
  • That local insights still work when AI is disabled or unavailable.

Why a server proxy matters

A Gemini API key should not be hardcoded into a browser bundle. A server-side proxy keeps the key in an environment secret, validates the request, limits the payload, and returns only a small structured response. Free-tier rate limits can still apply, so the UI should handle throttling and retries clearly.

What good AI budgeting sounds like

Good: “Dining is 32% over its plan, so a smaller restaurant budget next month may make the current pattern easier to follow.” Bad: “You should cancel your card” or “Buy this investment.” Keep the assistant specific, calm, and bounded.
